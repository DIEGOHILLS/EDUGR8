# EduGr8 – Full-Stack Learning Platform

EduGr8 is a modern educational platform built to help students browse courses, track progress, and access learning materials — powered by a scalable Supabase backend.

## 🛠 Tech Stack

- React + TypeScript
- Supabase (PostgreSQL, Auth, Storage)
- Tailwind CSS
- SQL Migrations
- Vite

## Features

- User authentication (login & signup)
- Course browsing
- Dynamic learning dashboard
- Database-backed content
- Responsive design

## Upcoming Features

- Role-based access (Student / Teacher / Admin)
- User profile customization
- Admin dashboard
- Payment simulation
